# wita-kit

**A name reservation for WITA, Deutsche Telekom's wholesale ordering interface. Nothing is
implemented.**

[![crates.io](https://img.shields.io/crates/v/wita-kit.svg)](https://crates.io/crates/wita-kit)

Service providers order, change and cancel lines on Telekom's network over WITA. This name is
reserved for that interface in [telco-interop](https://github.com/hupe1980/telco-interop),
alongside [`wbci`](https://crates.io/crates/wbci) and [`spri`](https://crates.io/crates/spri).

Unofficial; not affiliated with or endorsed by Deutsche Telekom.
