Open-source Rust crates · WBCI · S/PRI

The German provider switch, in Rust

WBCI 2.0 for the § 59 TKG Anbieterwechsel and Rufnummernportierung between providers, S/PRI 4.x for open-access fibre orders with the network owner: typed messages, XML proven against the official schemas, deadlines that explain themselves and the whole process as a value. Sans-I/O, so transport, signing and storage stay yours.

Get started How a switch works 
$ cargo add telco-interop

or only one interface: cargo add wbci · cargo add spri

Why you can rely on it

  • 373 + 776WBCI and S/PRI payloads validated against the official XSDs on every CI run
  • Fuzzedhostile XML refused with its receipt code, never a panic
  • Sans-I/Ono network, no clock, no global state
  • Redactedpersonal data never in Debug, errors or logs
  • MSRV 1.88three external dependencies, no unsafe
  • MIT / Apache-2.0dual-licensed, open source

One switch, two interfaces

The gaining provider agrees the switch with the losing provider over WBCI, then orders the line from the network owner over S/PRI with the same Vorabstimmungs-ID. telco_interop::Wechsel shows it as one timeline and checks that both sides agree.

  1. VA-KUE-MRNEKPauf → EKPabgpre-agreement
  2. RUEM-VAEKPabg → EKPaufagreed, binding date
  3. AKM-TREKPauf → EKPabgtakes over the line
  4. PVEKPauf → networkprovider-switch order
  5. QEBnetwork → EKPauforder admissible
  6. AKM-PVnetwork → EKPabgswitch announced
  7. RUEM-PVEKPabg → networklosing side answers
  8. ABM · ABM-PVnetwork → bothdate confirmed
  9. ERLM · ERLM-PVnetwork → bothswitched
  10. ENTM · ENTM-PVnetwork → bothbilling date
